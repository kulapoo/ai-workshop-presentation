What is Agentic AI?

Agents can handle tasks with increasing independence, operating within defined boundaries and under human oversight.

Key Capabilities:

  • Make judgment calls within parameters
  • Adapt approach based on situation
  • Take initiative rather than waiting for instructions
  • Problem-solve independently when encountering obstacles

Prompt Engineering Essentials

What is Prompt Engineering?

Crafting instructions that guide AI models to generate desired outcomes

Why it matters: Cost-effective, accessible foundation before advanced techniques

Key Principle

"Clarity beats complexity"

Explicit instructions, relevant context, and systematic iteration produce better results than clever tricks

The TCREI Framework

"Thoughtfully Create Really Excellent Inputs"

📝 Task - Define What You Want

  • Assign persona ("You're a marketing expert...")
  • Specify output format (table, bullets, paragraphs)

🎯 Context - Provide Details

Background information, goals, constraints

📚 References - Show Examples

Provide 2-5 concrete examples with clear labels

✅ Evaluate - Check Output

Accuracy, bias, relevance, consistency

🔄 Iterate - Refine & Improve

Break prompts into shorter sentences, try different phrasing

Core Techniques

Zero-Shot vs Few-Shot

Zero-Shot: "Classify sentiment: 'This exceeded expectations!'"

Few-Shot: Show examples first → "Great service!" → Positive

Prompt Chaining

Link outputs: Extract → Analyze → Generate → Format

Structured Output

Return format: <analysis> <summary>...</summary> <findings>...</findings> </analysis>

Quick Checklist:

  • Clear task with persona & format?
  • Sufficient context provided?
  • Examples included (when helpful)?
  • Ready to iterate?

Prompt Examples

❌ Bad Prompt

"Generate a market analysis report for a new product category."

✅ Good Prompt

Parameters: Temperature: 0.9, Top p: 0.999, Max length: 5,000

Prompt:

Generate a comprehensive market analysis report for a new product category in the finance industry for an audience of small and medium-sized businesses (SMBs). Structure the report with:

  1. Executive Summary
  2. Industry Overview
  3. Target Audience Analysis
  4. Competitive Landscape
  5. Product Opportunity and Recommendations
  6. Financial Projections

The tone should be professional and tailored to SMBs.
